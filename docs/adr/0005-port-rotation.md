# ADR-0005 端口轮试：候选列表为契约，TCP/UDP 分开选择，订阅 URL 不含端口

状态：proposed（2026-11-10）

## 背景
用户不接受固定 443（被他人占用时无法启动）。现实现：TCP 与 UDP 必须同时空闲；避让结果写盘后永久粘在新端口；启用 `SO_REUSEPORT` 使两个实例可静默共享端口；client 端口缓存仅在内存。

## 备选
1. 固定 443，占用即失败。
2. 任意空闲端口，订阅中写明端口。
3. 固定候选列表内轮试，订阅 URL 只表示节点身份，client 按列表探测并缓存。

## 理由
选 3。保留“免端口订阅”的外观，同时允许避开他人占用；列表固定使 client 无需额外信息。

## 后果
- 仅官方 client 能做到免端口；第三方工具在 443 被占时打不开订阅 URL。
- 端口选择持久化于 SQLite，启动时优先沿用；独占锁文件；去掉 `SO_REUSEPORT`。
- client 订阅拉取同时支持 HTTP/3；成功端口落盘。
- 会话中途端口跳变需 edge 写 nftables DNAT（宿主状态，见 PROJECT_RULES）。
- 端口轮试不能应对整体 UDP 封锁；该情况返回 `CLIENT_UDP_BLOCKED`。
