# ADR-0015 Windows 不再需要崩溃守护进程（guard）

状态：accepted（2026-11-11）
关系：取代 ADR-0013 第 7 条中“Windows 由 guard 进程在父进程退出后删除自有网卡”。

## 背景
旧 guard（`cmd/guard`）在客户端崩溃后执行 netsh 删除路由、PowerShell 删除 NRPT。ADR-0013/0014 之后客户端不再产生这些状态；ADR-0013 曾计划让 guard 改为删除自有网卡。

## 依据
用户 Windows 主机实测（`docs/host-state-verification.md`）：wintun 0.14.1 创建的网卡在创建进程被强杀后 0.74 秒内由系统删除，其上的地址、路由随之消失；WFP 动态会话规则同样由内核删除。

## 决定
删除 `cmd/guard` 及其构建、打包与隔离门禁映射。客户端无需任何外部进程兜底。

## 后果
- Windows 发布包少一个可执行文件；崩溃恢复完全依赖操作系统对进程资源的回收。
- 若将来更换为生命周期不随进程的网卡驱动，必须重新评估并补充兜底机制。
