# ADR-0007 IPv6：外层双栈，内层 ULA + NAT66，带启动自检门禁

状态：proposed（2026-11-10）

## 背景
现实现从宿主公网 /64 分配地址，无 NDP 代理、共享 /64 时冒用邻居地址；生产代码拒绝 ULA 池；TUN 与 PTB 网关地址不一致；client DNS 永不返回 AAAA。用户要求保留 IPv6。

## 备选
1. 移除内层 IPv6。
2. 路由前缀 + NDP 代理。
3. ULA + NAT66，与 IPv4 NAT 对称。

## 理由
选 3。适用于只有单个 IPv6 地址的 VPS；行为与 IPv4 一致，便于测试。

## 后果
- 启动自检 IPv6 出站，通过后才在订阅声明；否则 client 走黑洞。
- ip6tables / nft 补 MSS 钳制；PTB 网关取 TUN 实际地址。
- `ai`、`browser` 场景 IPv6 出口地理位置与 IPv4 不一致时只走 IPv4。
- 每个场景地址池都需 IPv6 子网。
