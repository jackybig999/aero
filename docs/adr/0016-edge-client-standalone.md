# ADR-0016 edge 与 client 独立可部署；中台只经接口管理节点

状态：proposed（2026-11-12 起草，待用户确认）
关系：收紧 ADR-0011（中台经 SSH 的运维面范围）；ADR-0001 的运行面约束不变。

## 背景
用户 2026-11-12：“服务端和客户端是一个独立运行的项目，中台主要职责是订阅系统（管理节点和安装等功能只是调取 GitHub 和服务端的接口，不能影响服务端），都相对独立，通过接口实现连接……没有中台，服务端和客户端都能自己部署实现功能。服务端和客户端是整个系统的基石。”

审查发现（已修复）：删除中台记录会经 SSH 卸载 edge 并 `pkill -9 -f aero`、`fuser -k 443/tcp`（cd7b76d）；调用 edge 时跳过证书校验、密钥放在 URL 与节点上的命令行（96b5225）；SSH 失败时伪造“运行中”（96b5225）。
仍存在：中台经 SSH 读取 edge.json 中的密钥、扫描与删除证书目录、采集主机负载、在节点上运行纯净度探测、`systemctl restart`。

## 决定
1. edge、client 各自独立构建、部署、运行、维护；不依赖中台的可用性（edge 不调用中台；签名 token 离线验签）。
2. 中台对节点只有三种通道：
   - GitHub release：下载 edge 发布物（版本号 + SHA256SUMS 校验）。
   - SSH：仅用于安装、升级、显式卸载 edge 程序本身（写入二进制、服务单元、首次最小配置）。安装后不再读写 edge 的任何文件。
   - edge 接口：C6（计量，只读）与 C13（远程管理，api/edge-remote.yaml）。中台需要的新能力先在 edge 契约中增加接口，由 edge 实现。
3. 删除中台记录只影响中台登记；卸载必须是显式操作，且只停止并删除 aero-edge 自己的单元与文件，不按名称或端口终止进程。
4. 中台调用 edge 一律按节点域名校验证书，密钥只放 Authorization 头。

## 后果
- 中台中经 SSH 实现的状态、诊断、纯净度、证书、重启、密钥回读，在 C13 实现后改为接口调用，SSH 版本删除。
- edge 需实现 C13；未鉴权时返回伪装站（现有 /admin/* 对错误密钥返回 403，暴露接口存在，一并修正）。
- 没有域名的节点无法被中台安全管理（不会向无法校验身份的对端发送密钥）。
