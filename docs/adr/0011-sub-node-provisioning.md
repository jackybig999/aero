# ADR-0011 中台经 SSH 开通节点（运维面），运行面仍只读

状态：accepted（2026-11-10，用户决定）
关系：部分取代 ADR-0001 中“sub 不写 edge”对**运维面**的约束；运行面约束不变。

## 背景
中台（internal/sub）可通过 SSH 登录 VPS 安装与升级 edge（vps 表 ssh_password_enc、probe.go）。ADR-0001 规定 sub 不写 edge。用户要求保留该能力以实现基本自动化，并询问能否改为密钥登录。

## 备选
1. 删除远程开通，运维手工安装后在中台登记节点。
2. 拆为独立的节点开通工具。
3. 保留在中台，区分运维面与运行面，并加固 SSH。

## 决定
选 3（用户决定）。
- 运维面：中台可经 SSH 执行“安装/升级/重启 edge 二进制”这一类操作。
- 运行面：用户、token、计量、订阅等业务数据，中台只通过 edge 的只读接口（C6）获取；edge 不调用中台；中台不经 SSH 读写 edge 的业务数据文件。

## SSH 加固（后续实施）
- 每节点独立 Ed25519 密钥；首次开通用一次性密码（或运维提供的公钥）写入 authorized_keys 后，密码立即丢弃、不落盘。
- 私钥加密存储（复用现有加密机制）。
- 首次连接记录主机指纹，之后严格校验（防中间人）。
- 远程命令固定为安装脚本的版本化 URL + 校验和，禁止拼接任意命令。

## 后果
- 中台从“推送到 edge”（/admin/subs）与“接收 edge 推送”（/admin/metering）改为拉取 C6 接口；相关代码清理。
- 中台被攻破的影响面：可登录节点（运维面）。密钥化与指纹固定降低但不消除该风险，已由用户知悉并接受。
